# CodeSync

[Tae Seong Hong](https://github.com/tshong3) (C++)과 [Hyun-suck Lee](https://github.com/leehyunsuck) (Java)가 모여 코딩 테스트 문제 풀이를 공유하고 알고리즘을 학습하는 저장소이다.

## 프로젝트 목적
- 알고리즘 문제 해결 능력 향상
- C++ 및 Java를 활용한 다양한 문제 풀이 방식 공유
- 지속적인 코드 리뷰 및 학습 내용 기록
